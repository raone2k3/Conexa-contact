# 📇 Conexa

A modern contact management web application built with HTML, CSS, and JavaScript.

Conexa allows users to create, search, manage, and delete contacts directly from the browser. Contact information is stored locally using the browser's `localStorage`, so no backend or database is required.

[View Contactly Live](YOUR_GITHUB_PAGES_LINK)

## ✨ Features

- ➕ Add new contacts
- 🖼️ Upload profile images
- 💾 Store contacts using `localStorage`
- 🔍 Search contacts in real time
- 🏷️ Categorize contacts by priority
- 🌙 Light / Dark mode
- 🗑️ Delete contacts with confirmation
- 🔢 Dynamic contact counter
- 📱 Responsive design
- 🔎 Displays a user-not-found state when no contacts match the search
- 💻 Fully client-side application

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Browser LocalStorage API
- FileReader API
- Git & GitHub
